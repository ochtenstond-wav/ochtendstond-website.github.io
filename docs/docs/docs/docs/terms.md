# Algemene voorwaarden template

## Betaling
Een project wordt pas definitief ingepland na bevestiging en eventueel voorschot.

## Annulatie
Bij annulatie kort voor de shoot kunnen voorbereidingskosten worden aangerekend.

## Revisies
Standaard is één revisieronde inbegrepen, tenzij anders afgesproken.

## Oplevering
De finale bestanden worden digitaal geleverd via downloadlink.

## Raw footage
Raw footage wordt niet standaard meegeleverd, tenzij vooraf afgesproken.

## Gebruik
De klant mag de afgewerkte video gebruiken voor de afgesproken kanalen.

## Portfolio
Ebben mag het project gebruiken als portfolio, tenzij vooraf anders afgesproken.
